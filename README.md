## ⚙️ Hướng Dẫn Cài Đặt & Chạy Dự Án

1. Clone repository về máy:
```bash
   git clone https://github.com/username/ten-repo.git
```
2. Di chuyển vào thư mục dự án:
```bash
   cd ten-repo
```
3. Mở file `index.html` bằng trình duyệt (hoặc dùng Live Server trong VS Code)

*(Nếu có back-end, bổ sung thêm bước cài đặt `npm install`, cấu hình `.env`, chạy `npm start`...)*

## 📖 Quy Trình Làm Việc Nhóm (Git Workflow)

- Nhánh `main`: chứa code ổn định, chỉ merge sau khi đã kiểm tra
- Mỗi thành viên tạo nhánh riêng khi phát triển tính năng: `feature/ten-tinh-nang`
- Quy trình:
```bash
  git checkout -b feature/ten-tinh-nang
  git add .
  git commit -m "Mô tả ngắn gọn thay đổi"
  git push origin feature/ten-tinh-nang
```
- Tạo Pull Request → các thành viên review → merge vào `main`
