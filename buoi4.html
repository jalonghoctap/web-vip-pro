Giới thiệu

Về Bản Thân Tôi

Xin chào! Tôi là Trần Khắc Đạt, sinh viên ngành Công nghệ Thông tin tại Trường Đại học Lạc Hồng. Tôi yêu thích việc xây dựng các giao diện web hiện đại theo chuẩn Design System, thiết kế trải nghiệm người dùng (UI/UX) trên Figma, phát triển phần mềm bằng Python và nghiên cứu các giải pháp nhà thông minh với vi điều khiển ESP32.

Lĩnh vực chuyên môn

Dịch Vụ Cung Cấp (Services)

Phát triển Web

Xây dựng giao diện Responsive với HTML5, CSS3 Grid/Flexbox, JavaScript và tùy biến giao diện WordPress.

Thiết kế UI/UX

Thiết kế User Flow, Wireframe, Component Library và Prototype tương tác trên Figma.

Giải pháp IoT

Lập trình vi điều khiển ESP32, tích hợp cảm biến tự động và truyền thông không dây ESP-NOW.

Cơ sở dữ liệu

Thiết kế sơ đồ thực thể kết hợp (ERD), chuẩn hóa dữ liệu và truy vấn T-SQL trên SQL Server.
